## First launch and existing data

A genuinely new installation displays the one-time form for the company, administrator's full name, username, password and confirmation. After setup, sign in with that account. There is **no bundled default administrator/password**. Server-side validation, scrypt hashing and an immediate SQLite transaction prevent duplicate first administrators, including simultaneous requests.

If you see **Sign in** even though *you* never created an administrator, an earlier `%APPDATA%\GENESIS\genesis.db` may have been selected. That database can contain registered accounts and business records; the archived project copy does, but **we cannot inspect the database on your PC from here**. On the first launch of this update, a native dialog lets you keep using the older GENESIS records (default) or explicitly start a **separate, EMPTY** JENESIS installation. The second choice requires another confirmation, restarts the app, and then shows the first-run form. On the desktop sign-in/recovery/setup screen you can switch between the two installations later. Neither action imports, merges, resets or deletes the original accounts, business data or backups. An account created in the **new** installation **does not unlock the old records**. For access to those records, use an existing account or ask an authorized administrator/technician to follow the documented **offline, backed-up recovery** in the source archive's `DESKTOP.md`. Do not delete the old database or attempt first-run registration over it. Remote LAN browser clients cannot select a host database.

## Use and limits

Seller (red), Administrator (blue) and Network & Maintenance (green) are independent entry points into the selected host database, with server-enforced role, mode and company permissions. Only Seller and Administrator have a display-only calculator. English, French and Kinyarwanda and offline Help are bundled. Company base currencies include **XAF, RWF, USD, EUR and UGX**; no automatic FX conversion or jurisdiction-certified tax treatment is provided. Have an accountant verify results before regulated use.

The service is loopback-only by default. An authorized local user can opt into private **HTTPS LAN browser access** on port `34671`; clients must verify the host certificate fingerprint through a separate trusted channel and authenticate against the *same* host database. There is no installed desktop-client sync. Do not copy or merge live SQLite files. Keep off-PC verified backups before installation, upgrade, restore or uninstall. See `README.md` and `DESKTOP.md` inside the source archive for safety and recovery instructions.
